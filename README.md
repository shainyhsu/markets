# Live Rate & Charts

Live FX / quote conversion and short-horizon price charts (e.g. BTC, gold).

**Live demo:** https://shainyhsu.github.io/markets/

## Features

- Instant rate conversion
- Symbols such as BTC and XAU
- Price charts for the last 1 hour, 24 hours, 3 days, and 7 days (USD)

## How to use

Open the site. Quotes are fetched in the browser from public market data sources (as implemented on the page).

## Tech

Single HTML page on GitHub Pages.
